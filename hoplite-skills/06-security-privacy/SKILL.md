# Security / Privacy
Process screenshots/voice ephemerally by default.
Do not persist raw private media unless explicitly saved.
Minimize logs containing raw private content.
API keys and Appwrite server keys stay server-side.
Social data is opt-in. Implement/retain block and report paths where Connect is enabled.
Use least-privilege Appwrite permissions.

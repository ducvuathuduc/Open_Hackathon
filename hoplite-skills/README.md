# Hoplite Skills

These folders are reusable instruction bundles for YapYep.

Recommended project-level use:
- keep `AGENTS.md` at repo root,
- import/copy these skills into the Hoplite project skill mechanism supported by your workspace,
- enable only the relevant skill(s) per agent/thread,
- keep `07-quality-gate` enabled for all code-writing threads.

Hoplite's current docs describe Agent Skills as reusable instruction bundles and support importing existing local skills/config. Exact UI/import steps may change, so follow the current Hoplite project UI/docs rather than hard-coding a local path convention.

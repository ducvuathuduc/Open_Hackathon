# YapYep Master Spec v1.0

This file is a compact single-document summary. Detailed normative rules live in the referenced docs.

## Product
YapYep — ASEAN Student Adaptation Network.

## Platform
Mobile-first web/PWA, current Vite + React + TypeScript project.

## Core
- YapLens: understand the moment
- YapSim: practice the moment
- Study Copilot: learn in the academic moment
- MyDNA / CountryDNA / ContextDNA / UniversityDNA / PairDNA
- Country Passport + Today
- Connect + Local Verify
- ASEAN Passport progress

## Product loop
UNDERSTAND → PRACTICE → INTERACT → REFLECT → ADAPT.

## Scope
11 ASEAN countries, 110 directional home→host pairs.

## P0
Auth, Journey, MyDNA, PairDNA, Today, Passport, Lens text+screenshot, source/confidence, Sim, skill persistence, deployed phone URL.

## Frozen navigation
Today / Passport / Lens / Explore / Connect.

## Frozen tech
Vite/React/TS/Tailwind/shadcn/Motion/TanStack/Zod/PWA.
Appwrite backend.
Gemini 3.7 Flash primary.
Gemini 3.1 Flash Live optional.
Embedding 2 optional.

## Critical trust rules
- no deterministic culture stereotypes
- no unsourced admin facts
- server-side secrets only
- structured AI outputs validated
- raw screenshot/voice not persisted by default
- social users are opt-in only
- no architecture changes without decision record
